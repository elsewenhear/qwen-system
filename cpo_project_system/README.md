# CPO Project Management System

Система управления проектами для CPO (Chief Product Officer) на базе SQLite.

## 📁 Структура файлов

```
cpo_project_system/
├── schema.sql          # Схема базы данных (таблицы, триггеры, индексы)
├── seed_data.sql       # Примеры данных для 3 проектов
├── cpo_system.py       # CLI-интерфейс для управления
├── cpo_projects.db     # База данных SQLite (создаётся автоматически)
└── README.md           # Этот файл
```

## 🚀 Быстрый старт

```bash
cd /workspace/cpo_project_system

# 1. Инициализировать базу данных
python3 cpo_system.py init

# 2. Загрузить тестовые данные (опционально)
python3 cpo_system.py seed

# 3. Показать все проекты
python3 cpo_system.py list

# 4. Показать детали проекта
python3 cpo_system.py show 1
```

## 📋 Команды

### Основные
| Команда | Описание |
|---------|----------|
| `init` | Инициализировать базу данных |
| `seed` | Загрузить тестовые данные |
| `list [status]` | Показать все проекты (можно фильтровать по статусу) |
| `show <id>` | Подробная информация о проекте |
| `stats` | Статистика по проектам |

### Управление
| Команда | Описание |
|---------|----------|
| `add <code> <name> [priority] [status]` | Добавить новый проект |
| `status <id> <new_status> [reason]` | Изменить статус проекта |
| `artifact <id> <type> <title> [desc]` | Добавить артефакт |

## 📊 Структура данных

### Таблицы

**projects** — основные проекты:
- `code` — уникальный код проекта (например, MOB-APP-01)
- `name` — название
- `current_status` — текущий статус
- `priority` — приоритет (Low/Medium/High/Critical)
- `meta_attributes` — JSON с динамическими атрибутами
- `tags` — теги для фильтрации

**status_history** — история изменений статусов:
- Автоматически заполняется при смене статуса
- Фиксирует: кто, когда, почему изменил

**artifacts** — артефакты проекта:
- Типы: Link, File, Note, Decision, Risk, Metric
- Каждое дополнение имеет метаданные в JSON

### Статусы по умолчанию
```
Инициация → Исследование → Разработка → Тестирование → Запуск → Завершён
                                         ↓
                                    Заморожен
```

## 💡 Примеры использования

### Добавить новый проект
```bash
python3 cpo_system.py add PROJ-001 "Новый проект" High Инициация
```

### Изменить статус с указанием причины
```bash
python3 cpo_system.py status 1 Разработка "Утверждение ТЗ получено"
```

### Добавить риск к проекту
```bash
python3 cpo_system.py artifact 1 Risk "Риск задержки API" "Бэкенд отстаёт"
```

### Добавить ссылку на документацию
```bash
python3 cpo_system.py artifact 1 Link "ТЗ в Confluence" "https://confluence/..."
```

### Посмотреть статистику
```bash
python3 cpo_system.py stats
```

## 🔧 Расширение системы

### Добавление своих полей в JSON
Динамические атрибуты хранятся в JSON-поле `meta_attributes`. Можно добавлять любые поля без изменения схемы:

```python
# Пример при создании проекта
meta = {
    "team_size": 5,
    "budget_usd": 100000,
    "tech_stack": ["Python", "React"],
    "custom_field": "любое значение"
}
```

### Новые типы артефактов
Добавьте новый тип в CHECK-ограничение таблицы `artifacts`:
```sql
artifact_type TEXT CHECK(artifact_type IN ('Link', 'File', 'Note', 'Decision', 'Risk', 'Metric', 'YourType'))
```

## 🛠️ Технологии

- **SQLite** — лёгкая база данных (один файл)
- **Python 3** — CLI-интерфейс
- **JSON** — гибкие метаданные
- **Триггеры** — автоматическое ведение истории

## 📝 Рекомендации для CPO

Эта система реализована на **SQLite + Python** потому что:

| Критерий | Решение |
|----------|---------|
| **Простота** | Один файл БД, не нужен сервер |
| **Гибкость** | JSON-поля для любых метрик |
| **Надёжность** | История изменений автоматически |
| **Быстрота** | Мгновенный старт, нет настройки |
| **Расширяемость** | Легко добавить новые поля/типы |

### Альтернативы для сравнения:

| Инструмент | Когда использовать |
|------------|-------------------|
| **Эта система (SQLite)** | ✅ Лучший выбор для одного CPO, полный контроль |
| **Airtable** | Если нужен GUI и совместная работа |
| **Notion** | Если уже используете Notion для всего |
| **Excel/Google Sheets** | Только для очень простых случаев (< 10 проектов) |

## 📞 Поддержка
