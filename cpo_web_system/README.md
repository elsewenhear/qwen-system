# CPO Project System - Веб-интерфейс

Система управления проектами для директора по продукту (CPO).

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install flask
```

### 2. Запуск сервера
```bash
cd /workspace/cpo_web_system
python run.py
```

### 3. Открыть в браузере
```
http://localhost:5000
```

## 📋 Возможности системы

### Управление проектами
- ✅ Создание, редактирование, удаление проектов
- ✅ Уникальный код проекта (например: MOB-APP-01)
- ✅ Приоритеты: High, Medium, Low
- ✅ Теги для кросс-фильтрации
- ✅ Динамические JSON-атрибуты для любых метрик

### Отслеживание статусов
- ✅ Статусы: Инициация → Исследование → Разработка → Тестирование → Запуск → Завершён/Заморожен
- ✅ Автоматическая история всех изменений статуса
- ✅ Фиксация автора, времени и комментария к каждому изменению

### Артефакты проекта
- ✅ Ссылки (документация, макеты, задачи)
- ✅ Файлы (пути к документам)
- ✅ Заметки
- ✅ Решения
- ✅ Риски
- ✅ Метрики

### Фильтры и поиск
- ✅ Поиск по названию, коду, описанию
- ✅ Фильтр по статусу
- ✅ Фильтр по приоритету
- ✅ Дашборд со статистикой

## 🗄️ Структура базы данных

### Таблица `projects`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | ID проекта |
| name | TEXT | Название |
| code | TEXT | Уникальный код |
| description | TEXT | Описание |
| owner | TEXT | Владелец |
| priority | TEXT | Приоритет |
| current_status | TEXT | Текущий статус |
| start_date | TEXT | Дата начала |
| end_date | TEXT | Дата окончания |
| meta_attributes | JSON | Динамические атрибуты |
| tags | JSON | Теги |
| is_archived | INTEGER | Архивирован |

### Таблица `status_history`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | ID записи |
| project_id | INTEGER | Ссылка на проект |
| status_name | TEXT | Новый статус |
| changed_at | TEXT | Время изменения |
| changed_by | TEXT | Автор изменения |
| comment | TEXT | Комментарий |

### Таблица `artifacts`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | ID артефакта |
| project_id | INTEGER | Ссылка на проект |
| type | TEXT | Тип (Link/File/Note/Decision/Risk/Metric) |
| title | TEXT | Название |
| content_url | TEXT | URL или путь |
| description | TEXT | Описание |
| created_at | TEXT | Дата создания |

## 💡 Примеры использования

### Добавление проекта с метриками
1. Нажмите "+" в правом нижнем углу
2. Заполните основные поля
3. В поле "Дополнительные атрибуты" укажите JSON:
```json
{
  "team_size": 6,
  "budget": 500000,
  "platform": "iOS/Android",
  "sprint_duration": 2
}
```

### Смена статуса
1. Откройте проект
2. Выберите новый статус в форме "Сменить статус"
3. Добавьте комментарий (опционально)
4. Укажите автора изменения
5. Нажмите "Изменить статус"

### Добавление артефакта
1. В деталях проекта найдите секцию "Артефакты"
2. Выберите тип (например, "Risk")
3. Укажите название и описание
4. Добавьте ссылку на документ (опционально)

## 🔧 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Список проектов |
| GET | `/project/<id>` | Детали проекта |
| POST | `/project/add` | Создать проект |
| POST | `/project/<id>/edit` | Редактировать проект |
| POST | `/project/<id>/status` | Сменить статус |
| POST | `/project/<id>/artifact/add` | Добавить артефакт |
| POST | `/project/<id>/archive` | Архивировать проект |
| GET | `/api/stats` | Статистика (JSON) |
